# 🤖 Robot Car

An Arduino-based smart robot car developed to demonstrate embedded systems, robotics, and IoT concepts. The project integrates motor control, sensors, and wireless communication to enable autonomous navigation and remote operation.

---

## 📖 Overview

The Robot Car project was developed as a practical embedded systems application using Arduino. It combines electronic hardware with software programming to control movement, detect obstacles, and interact with external devices.

This project demonstrates the fundamentals of robotics, sensor integration, and microcontroller programming while providing a scalable platform for future IoT and automation features.

---

## ✨ Features

- 🚗 Forward, Reverse, Left & Right movement
- 📡 Wireless remote control
- 🚧 Obstacle detection and avoidance
- 🔋 Motor driver integration
- 📟 Sensor-based navigation
- ⚙️ Arduino microcontroller programming
- 🔌 Embedded systems implementation
- 📈 Expandable for IoT applications

## 🚀 Getting Started

### Requirements

- Arduino IDE
- Arduino Uno
- L298N Motor Driver
- HC-SR04 Ultrasonic Sensor
- Robot Chassis Kit
- USB Cable

### Installation

1. Clone the repository

```bash
git clone https://github.com/ImeshPerera/Robot-Car.git
```

2. Open the Arduino project in Arduino IDE.

3. Install any required libraries.

4. Connect the Arduino board.

5. Upload the sketch.

6. Power the robot and start testing.
